## About the Activity

For Activity 7, I explored how ChatGPT and Gemini generate professional resumes using the same prompt and personal information.

I asked both AI tools to create a resume for an aspiring Operating Room (OR) Nurse. I compared the results based on structure, clarity, formatting, content, accuracy, and overall quality.

After evaluating both outputs, I created a final one-page resume combining the strengths of each tool.

## What I Learned

This activity helped me understand that different AI tools can produce different results even when given the same instructions.

I preferred ChatGPT's content because it included a professional objective and relevant clinical skills, while Gemini's formatting was more organized and easier to read.

One challenge was that both generated resumes occupied two pages and had too much empty space. I addressed this by creating a more compact, one-page resume.

I also realized that AI-generated information, especially clinical skills and qualifications, must be reviewed for accuracy before being used in an actual job application.

In the future, I can apply these skills when preparing resumes, application letters, and other professional documents.
