## About the Activity

For this activity, I created a one-page website for **Maison Sucrée**, my home-based baking brand, using AI-assisted website development through Replit.

The goal was to create an elegant, functional, and user-friendly website where customers could learn about the brand, browse available baked goods, view prices, and find ordering instructions.

I incorporated the brand's burgundy-and-cream color palette, original food photography, logo, and promotional materials to maintain a consistent visual identity.

The website includes a homepage, product menu, price list, brand introduction, preorder announcements, ordering instructions, and contact section.

## What I Learned

This activity helped me understand how AI tools can assist in website development, even without advanced coding experience. I learned that creating a website involves more than designing its appearance because navigation, readability, responsiveness, and functionality are equally important.

One challenge was communicating exactly how I wanted the website to look and ensuring that it matched my existing Maison Sucrée branding. I addressed this by writing a detailed prompt that explained the colors, typography, layout, product information, and use of my original photographs.

I also learned the importance of making websites accessible and easy to navigate on both computers and mobile devices.

In the future, I can apply these skills when developing websites, promoting a business, or creating digital resources for healthcare and education.
